
These are the commands that might be helpful for you on this adventure. 
You will also want to use the common flags you learned for some of these 
commands:

`ls`    -> list the files in the current directory
`cat`   -> print the contents of a file to the terminal
`cd`    -> change to a different directory
`pwd`   -> print what directory you're in
`rm`    -> delete a file
`rmdir` -> delete a directory
`mv`    -> move a file ALSO rename a file
`grep`  -> searches for a string of characters in a text file
`wc`    -> counts the words in its input
`chmod` -> changes the permissions on files and directories
`touch` -> updates the last time of modification on a file ALSO will 
         create the file if it didn't exist
`mkdir` -> create a directory
`man`   -> show the man page (manual) for a command
`echo`  -> prints its argument to the terminal. Userful with file redirection
`vim`   -> text editor for pros. We know `i`, `<ESC>`, and `:wq` - just the basics.
